## 发现并修复

`notesOf` 先尝试把 JSON 解析为字符串数组；Go 的 `json.Unmarshal` 即使返回类型错误，也可能已经分配或部分填充该数组。随后解析对象数组时，原数组中会残留空字符串；混合无效数组也可能返回部分结果。

修复：切换到对象数组格式前清空第一次解析的残留。回归断言验证对象数组只返回有效文字，混合无效数组不返回部分数据。
