# 拓扑与多机房配置

## 组织设备

交换机使用唯一 ID；节点用 IP 或 MAC 标识，并通过 `attach.switch` 和 `attach.port` 登记接线。端口位置可标注机柜、楼层或面板号。交换机间链路决定上游故障关联与路径分析。

示例数据只演示结构，不表示你的真实设备。用页面编辑最方便；批量迁移可使用 YAML 导入，但应先备份，再检查预览。

## 多机房

在「设置」新建、复制或改名机房。切换激活机房前先查看预览；同一时间只有一个机房激活。各机房拥有独立拓扑和运行配置，版本快照可用于回滚。回滚后确认监控对象、告警渠道与定时扫描符合当前现场。

## 参数与时段

默认每秒探测（最小间隔 200ms），超时 1000ms，数据包 32 字节，延迟告警阈值 100ms，丢包告警阈值 20%；设备可以单独覆盖。阈值应根据链路实际情况设置。启用监控时段后，只在指定时段探测和告警；跨午夜时段（如 `22:00` 到 `06:00`）受支持，手动暂停独立生效。

## 字段参考

详细 YAML 字段、完整示例和批量生成提示词见 [拓扑字段参考](../docs/topology-fields.md)。修改监听地址或拓扑文件路径后需要重启。
